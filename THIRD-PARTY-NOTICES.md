# Third-Party Notices

Camera Flight Check is internal Cherry Hill Programs software (see `LICENSE`),
but it vendors and links against third-party code and assets. This is an
inventory of everything under `camera-host/lib/` and `vendor/`, so the
obligation set is known and doesn't need to be reconstructed later from
installer history. It was assembled 2026-09 while it was still easy to trace
each file back to the installer/download it came from — see
`REMEDIATION-PLAN.md` CFC-02 for why.

These obligations trigger on **distribution**. Per the CFC-01 decision
(2026-09-19), this software is internal-only and not currently distributed
outside Cherry Hill Programs, so none of this blocks anything today — it's
recorded so the answer is ready the day that changes.
