Tutorial images for the walk-around "More info" popups.

Drop PNG photos here named <cardKey>-<stepNumber>.png and the app shows
them automatically (no code changes). Expected files:

  pole-1.png    pole-2.png    pole-3.png
  cap-1.png     cap-2.png     cap-3.png
  plug-1.png    plug-2.png    plug-3.png
  strobe-1.png  strobe-2.png  strobe-3.png
  back-1.png    back-2.png    back-3.png
  floor-1.png   floor-2.png   floor-3.png

Captions/titles for each step are edited in strings.js (walk.items).
